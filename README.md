# لوحة التوطين — بيت هايل

موقع ثابت (Static Site) يعرض نسب التوطين ونطاقات نطاقات للكيانات الثلاثة، ويُقرأ مباشرة من ملف `data/nitaqat.xlsx`.

## هيكل الملفات
```
index.html          الصفحة الرئيسية (تنبيهات + بطاقات الشركات)
materials.html       بيت هايل لمواد البناء
transport.html       بيت هائل للنقليات
maintenance.html     هائل لصيانة السيارات
assets/style.css     التصميم
assets/app.js        منطق القراءة والحساب والرسوم
data/nitaqat.xlsx     ملف البيانات (المصدر الوحيد للأرقام)
```

## طريقة النشر على GitHub Pages
1. أنشئ مستودع جديد على GitHub (مثلاً: `HAIL-HOUSE-NITAQAT`).
2. عبر GitHub Desktop: أضف هذا المجلد كمستودع محلي (Add Local Repository) وادفعه (Publish).
3. من إعدادات المستودع (Settings → Pages) فعّل GitHub Pages على فرع `main`.
4. الرابط سيكون بصيغة: `https://<username>.github.io/<اسم-المستودع>/`

## طريقة التحديث اليومي (الأهم)
كل ما تحتاجه هو **استبدال ملف واحد**:

1. افتح `data/nitaqat.xlsx` وعدّل عليه مباشرة (أضف موظف، احذف موظف، غيّر مهنة، انقله بين ورقة السعوديين وغير السعوديين… إلخ).
   - **لا تغيّر أسماء الأوراق (Sheets)** — يجب أن تبقى بنفس الصيغة:
     `مواد_البناء_سعوديين`, `مواد_البناء_غير سعوديين`, وهكذا لباقي الشركات.
   - الأعمدة يجب أن تبقى بنفس الترتيب: رقم الإقامة/الهوية، الاسم، الجنس، الجنسية، المهنة.
2. احفظ الملف بنفس الاسم `nitaqat.xlsx` في نفس المسار `data/`.
3. افتح GitHub Desktop → سيظهر لك التغيير على `data/nitaqat.xlsx` تلقائياً → اكتب رسالة (مثل "تحديث بيانات أغسطس") → Commit → Push.
4. خلال دقيقة إلى دقيقتين يتحدث الموقع تلقائياً بالأرقام الجديدة — بدون أي تعديل على أكواد الموقع نفسه.

## قرارات توطين المهن الرسمية
كل صفحة شركة تحتوي على قسم "الالتزام بقرارات توطين المهن" يقارن مسميات موظفيكم تلقائياً بقرارات وزارة الموارد البشرية والتنمية الاجتماعية (الإدارية المساندة 100%، المبيعات 60%، المشتريات 70%، التسويق 60%، المحاسبية 40-70%)، بالإضافة لتنبيه خاص بقرار "منافذ بيع الجملة والتجزئة" الذي يشمل نشاط بيع مواد البناء والرخام والسيراميك صراحة بنسبة 70% لكل منفذ بيع.

بيانات هذه القرارات مُضمّنة داخل `assets/app.js` (المتغيرات `PROFESSION_DECISIONS` و `OUTLET_DECISION`) وتم استخراجها من الأدلة الإجرائية الرسمية. إذا صدر قرار جديد أو تغيرت نسبة، حدّثها يدوياً هناك.

**تنبيه مهم**: المطابقة تعتمد على تطابق نص المسمى الوظيفي في ملف الإكسل مع القائمة الرسمية للمهنة (بعد تطبيع بسيط للتشكيل والألف/الياء). إذا كان المسمى الوظيفي في ملفكم مختلف قليلاً عن التصنيف السعودي الموحد للمهن، قد لا تُكتشف المطابقة تلقائياً — راجع القائمة الظاهرة تحت كل قرار للتأكد.

## ورقة "ارقام_قوى_الرسمية" — الأهم للدقة
موقعي يحاول يخمّن تلقائياً كم موظف يقع تحت كل قرار توطين مهن بمطابقة نص المسمى الوظيفي بملفكم مع قوائم المهن الرسمية. لكن هذا **تقدير فقط**، لأن قوى يحسب حسب **رمز المهنة المسجّل فعلياً في التأمينات الاجتماعية** لكل موظف، وهذا الرمز قد يختلف عن المسمى الداخلي المستخدم بالشركة حتى لو كان الاسم متشابه.

للحصول على أرقام دقيقة 100% مطابقة لقوى:

1. افتح في قوى: **منشآتي ← خدمات المنشأة ← تفاصيل توطين المهن لمنشآت الكيان**.
2. لكل قرار (مهن التسويق، الإدارية المساندة، المبيعات، المشتريات، المحاسبية)، سجّل: الإجمالي، عدد السعوديين، عدد غير السعوديين كما يظهر بالضبط في قوى.
3. افتح `data/nitaqat.xlsx` ← ورقة `ارقام_قوى_الرسمية` ← عبّي الصف المطابق (اسم الشركة بالضبط + اسم القرار بالضبط).
4. احفظ وارفع الملف عبر GitHub Desktop كالمعتاد.

بمجرد ما تعبّي رقم لصف معيّن، الموقع يستخدمه تلقائياً بدل التقدير التلقائي، ويظهر شارة خضراء "رقم معتمد من قوى" بدل الشارة الذهبية "تقدير تلقائي". الصفوف الفاضية تبقى تقديرية لحد ما تعبّيها.

## ملاحظة على طريقة الحساب
نسبة التوطين المعروضة = عدد السعوديين ÷ إجمالي الموظفين في كل شركة، وهي حساب مباشر ومبسّط.
الحساب الرسمي في منصة قوى قد يتضمن أوزاناً إضافية (نوع العقد، ذوي الإعاقة، دوام جزئي، إلخ)، لذلك تبقى منصة قوى هي المرجع الرسمي المعتمد، وهذه اللوحة أداة متابعة سريعة داخلية.

حدود النطاقات (Bands) الحالية مأخوذة من منصة قوى وموجودة داخل `assets/app.js` (كائن `COMPANIES`) — إذا تغيّرت الحدود مستقبلاً (تغيّر نشاط أو حجم المنشأة)، عدّلها هناك يدوياً.
